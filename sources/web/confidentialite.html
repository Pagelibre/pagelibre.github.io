PageLibre

Confidentialité

Aucune donnée n'est collectée

Tout reste sur votre appareil. Vos documents sont ouverts, modifiés et enregistrés directement sur votre ordinateur : ils ne sont jamais envoyés sur Internet.

Pas de cookies, pas de traqueurs, pas de statistiques

PageLibre n'utilise ni cookies, ni outils de mesure d'audience, ni publicité. Aucun compte n'est demandé.

Ce qui est gardé sur votre appareil

Pour votre confort, le navigateur conserve sur votre appareil uniquement : vos réglages d'affichage, un brouillon du document en cours (en cas de fermeture sans enregistrer) et la liste de vos fichiers récents. Vous pouvez tout effacer en supprimant les données du site dans les réglages du navigateur.

Pour fabriquer un PDF avec les polices de votre ordinateur, le navigateur peut vous demander la permission de les lire. Elles servent uniquement à ce PDF, sur votre appareil ; vous pouvez refuser.

Hébergement

L'application est publiée par GitHub Pages. Comme tout hébergeur web, GitHub peut enregistrer des journaux techniques (adresse IP) lors du téléchargement des fichiers de l'application ; PageLibre n'y a pas accès. Une fois installée, l'application fonctionne hors connexion.
